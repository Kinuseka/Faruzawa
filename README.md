# Faruzawa



[Faruzawa](https://faruzawa.com) is an anime viewing site. No signup and No ads.

The front page shows trending plus slices of popular and newly added titles. Popular and new each have their own paginated list. Search is the same catalog, different entry point.

This was created just for myself but it is built for everyone, plus its opensource so you can inspect the underlying logic on how this site works. Some code will remain hidden to ensure these practices are kept vague and to protect myself and the source against "copyright".

Beta (`v0.4.2`). Genres aren’t implemented yet. Catalog and video are pulled from outside services; when those shift, some shows or streams stop working until the backend is updated.

Named after Faruzan from *Genshin Impact*.
